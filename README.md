# NOVA STREAM — راهنمای راه‌اندازی

## ۱. Supabase
1. در https://supabase.com پروژه جدید بسازید.
2. در SQL Editor محتوای `schema.sql` را اجرا کنید (فقط یک بار؛ اگر قبلاً policyها را ساخته‌اید، پیش از اجرای دوباره بررسی کنید).
3. از Project Settings → API / Data API، **Project URL** و **publishable/anon key** را بردارید و در `config.js` جایگزین کنید. هرگز secret یا service_role key را در فایل عمومی قرار ندهید.
4. در Authentication → URL Configuration، بعد از انتشار، Site URL را آدرس واقعی Netlify بگذارید؛ آدرس را در Redirect URLs نیز اضافه کنید. تأیید ایمیل را فعال نگه دارید. برای ارسال ایمیل به همه کاربران، SMTP اختصاصی پیکربندی کنید؛ سرویس ایمیل پیش‌فرض Supabase محدودیت دارد.
5. Storage → bucket `videos` باید PRIVATE بماند؛ SQL این bucket را می‌سازد.

## ۲. Netlify
1. پوشه پروژه را در یک مخزن GitHub قرار دهید و از Netlify با **Import from Git** منتشر کنید؛ به‌این‌ترتیب توابع Netlify نیز deploy می‌شوند. برای این پروژه از drag-and-drop ساده استفاده نکنید چون ممکن است Functions را deploy نکند.
2. Build command خالی؛ Publish directory: `.` ؛ Functions directory: `netlify/functions` (در `netlify.toml` آمده است).
3. در Netlify → Site configuration → Environment variables دو متغیر `SUPABASE_URL` و `SUPABASE_ANON_KEY` با همان URL و کلید عمومی اضافه کنید و سایت را Redeploy کنید. این کلید عمومی برای توابع خواندن ویدیوهای تأییدشده است.
4. آدرس `https://YOUR-SITE.netlify.app` را از Netlify دریافت کنید. آدرس دلخواه فقط در صورت آزادبودن قابل انتخاب است.
5. در `robots.txt` مقدار `REPLACE_WITH_YOUR_NETLIFY_DOMAIN` را با نام دامنه واقعی جایگزین کنید و دوباره deploy کنید.

## ۳. گوگل
1. آدرس‌های `/sitemap.xml` و `/watch/<video-id>` را آزمایش کنید.
2. سایت را در https://search.google.com/search-console/ ثبت و مالکیت را تأیید کنید.
3. آدرس `https://YOUR-SITE.netlify.app/sitemap.xml` را ثبت کنید. ایندکس شدن تضمینی نیست و ممکن است زمان ببرد.
4. فقط ویدیوهای approved در sitemap و صفحه عمومی نمایش داده می‌شوند. برای نتایج غنی ویدیویی بهتر، تصویر بندانگشتی، مدت‌زمان، و metadata دقیق نیز در نسخه بعدی اضافه شود.

## ۴. مدیریت محتوا
- ویدیوها به‌طور پیش‌فرض `pending` هستند؛ مدیر باید محتوا را بررسی کند.
- برای تأیید، در Supabase Table Editor رکورد مربوط را باز کنید و `status` را به `approved` تغییر دهید. برای ردکردن `rejected` را انتخاب کنید. این کار را فقط از داشبورد مدیر انجام دهید.
- حتماً پیش از پذیرش کاربران واقعی، قوانین محتوا، روش گزارش تخلف، رسیدگی به درخواست حذف، کنترل سوءاستفاده و محدودیت مصرف را آماده کنید.

## نکات و محدودیت‌ها
- آپلود هر فایل حداکثر ۵۰MB است؛ محدودیت‌های پلن رایگان و پهنای‌باند Supabase/Netlify ممکن است زودتر اعمال شوند.
- این نسخه پایه است: پروفایل عمومی، دنبال‌کردن، لایک، نظرات، گزارش تخلف، حذف حساب و پنل مدیریت مستقل هنوز پیاده‌سازی نشده‌اند.
- برای جلوگیری از سوءاستفاده عمومی، پیش از راه‌اندازی بزرگ rate limit، CAPTCHA و پایش هزینه‌ها را اضافه کنید.
- به‌منظور دسترسی امن، فایل‌های ویدیو در bucket خصوصی ذخیره می‌شوند و برای کاربران مجاز لینک پخش موقت صادر می‌شود.


## NOVA PREMIUM (نسخه نمایشی)
- دکمه «ارتقا به PREMIUM» در صفحه اصلی به `/premium.html` می‌رود.
- صفحه اشتراک، طرح‌های ماهانه و سالانه را نشان می‌دهد.
- دکمه‌های خرید **نمایشی هستند** و هیچ پرداختی انجام نمی‌دهند.
- دکمه FREE کاربر را به صفحه اصلی بازمی‌گرداند.
- برای فروش واقعی لازم است یک ارائه‌دهنده پرداخت مجاز متصل شود؛ پرداخت در سرور تأیید شود و فقط پس از تأیید، دسترسی ویژه در دیتابیس فعال گردد.
- قبل از فروش واقعی، شرایط خدمات، سیاست بازپرداخت، حفاظت از داده و قوانین محلی را آماده کنید.
